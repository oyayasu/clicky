# Atalhos do Clicky 0.2

`Mod` = Ctrl no Windows / Cmd (⌘) no Mac. `Alt` = Alt (Windows) / Option (Mac). Os navegadores e o WebView podem reservar algumas teclas.

| Função | Atalho |
| --- | --- |
| Negrito, itálico, sublinhado | Mod+B / Mod+I / Mod+U |
| Desfazer / refazer | Mod+Z / Mod+Shift+Z, ou Mod+Y |
| Copiar, recortar, colar | Mod+C / Mod+X / Mod+V (sistema) |
| Colar sem formatação | Mod+Shift+V (WebView) |
| Salvar documento | Mod+S |
| Exportar backup do documento | Mod+Shift+S |
| Novo documento | Mod+N |
| Abrir arquivo Clicky | Mod+O |
| Imprimir / PDF | Mod+P |
| Adicionar comentário | Mod+Alt+M |
| Painel de comentários | Mod+Alt+Shift+A |
| Localizar / substituir | Mod+F / Mod+H |
| Contagem de palavras | Mod+Shift+C |
| Dicionário | Mod+Shift+Y |
| Inserir link | Mod+K |
| Alinhar esquerda/centralizado/direita/justificar | Mod+Shift+L / E / R / J |
| Lista numerada / marcadores | Mod+Shift+7 / Mod+Shift+8 |
| Títulos 1 a 3 | Mod+Alt+1 / 2 / 3 |
| Aumentar / diminuir fonte | Mod+Shift+. / Mod+Shift+, |
| Remover formatação | Mod+\\ |
| Guias 1 a 9 | Mod+1 a Mod+9 |
| Nova guia | Shift+F11 |
| Pesquisar comandos | Alt+/ |
| Lista de atalhos | Mod+/ |
| Menus (Windows) | Alt+F (Arquivo), Alt+E (Editar), Alt+V (Ver), Alt+I (Inserir), Alt+O (Formatar), Alt+T (Ferramentas), Alt+H (Ajuda) |

**Não é ainda uma réplica integral dos atalhos do Google Docs.** Atalhos de funcionalidades não implementadas (sugestões colaborativas, mala-direta, equações, tabelas avançadas, gráficos e similares) ficam pendentes. Os atalhos com Ctrl/Cmd e Alt/Option podem conflitar com atalhos reservados de um sistema operacional, teclado ou navegador.

Documentação de referência do Google Docs: https://support.google.com/docs/answer/179738
